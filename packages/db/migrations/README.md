# Migrations

Applied in **filename order** by `bin/migrate.mjs`, tracked once each in the
`_migrations` ledger.

Two kinds of file live here and they interleave by name, not by author:

- `NNNN_<drizzle-name>.sql` — generated by `drizzle-kit generate` from
  `src/schema.ts`. The name after the number is drizzle's, and it is paired
  with `meta/NNNN_snapshot.json`; renaming one without the other breaks the
  next `generate`.
- `NNNN_<purpose>.sql` — hand-written, for constraints and triggers drizzle
  cannot express.

`0001_constraints.sql` and `0001_sudden_morlocks.sql` share a number on
purpose: they are not duplicates. `_constraints` sorts first and applies to
tables `0000` created; the generated one adds the `runs` tables. If that ever
becomes confusing, fix it by adding files, never by renumbering applied ones —
the ledger records the name it ran.
